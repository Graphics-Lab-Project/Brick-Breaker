- Pause: dim ≥ 0.8, title PAUSED, RESUME / OPTIONS / QUIT TO MENU with wrapping keys, Return activates, P/Escape → `resume()`, mouse click activates.
- Banner: `LEVEL 01`, `CLEAR`, `NEXT LEVEL 02` (after 10 comes 01). `play()`: bar width 0 → 336 over 600 ms OutCubic when polish is on, else 336 immediately.
