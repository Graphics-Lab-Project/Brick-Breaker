# [U1] UI: Brick component

| Model | Wave | Area | Depends on |
|---|---|---|---|
| sonnet | 1 | ui | none |

## Goal
Draw one brick from `hitsLeft`/`unbreakable`/`alive` with the T1 hit flash.

## Allowed files (the ONLY files you may change)
- qml/Brick.qml

## Interfaces (frozen)
- `qml/Brick.qml`: the Phase 0 stub's properties, signals, functions and the listed required `objectName`s.
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/qml/tst_brick.qml`
- ctest name: `tst_brick`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/U1 -G Ninja >/dev/null   # once
  cmake --build build-agents/U1
  ctest --test-dir build-agents/U1 --output-on-failure -R "^tst_brick$"
  ```

## Spec notes
- Tier 3 solid amber, tier 2 solid red, tier 1 hollow red (deep-red fill, 1 px red border), silver grey with a light border.
- Hidden when not alive. `flash()`: white `hitFlash` overlay 1 → 0 over 60 ms (optional 2 px squash that restores). T1 effects run only when `polish` is true; with `polish: false` the component is static and fully correct.
- Look: `docs/DESIGN_HANDOFF.md` §3 and §6 and the design PNGs.
