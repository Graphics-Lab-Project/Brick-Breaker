# [U7] UI: options screen

| Model | Wave | Area | Depends on |
|---|---|---|---|
| sonnet | 1 | ui | none |

## Goal
Paddle speed (1–5) and acceleration ON/OFF (mockup 06). Requests changes; the parent applies them.

## Allowed files (the ONLY files you may change)
- qml/OptionsScreen.qml

## Interfaces (frozen)
- `qml/OptionsScreen.qml`: the Phase 0 stub's properties, signals, functions and the listed required `objectName`s.
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/qml/tst_options_screen.qml`
- ctest name: `tst_options_screen`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/U7 -G Ninja >/dev/null   # once
  cmake --build build-agents/U7
  ctest --test-dir build-agents/U7 --output-on-failure -R "^tst_options_screen$"
  ```

## Spec notes
- Rows speed / acceleration / back, Up/Down clamped. Left/Right on speed emit `paddleSpeedRequested(±1)` only if the value changes.
- Acceleration: Left = ON, Right = OFF (emit only on change), Return toggles. Back row + Return or Escape anywhere → `back()`.
- The component never changes its own `paddleSpeed`/`acceleration`; the parent does.
