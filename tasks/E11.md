## Goal
The four QAbstractListModels QML renders: bricks, balls, capsules, projectiles.

## Allowed files (the ONLY files you may change)
- src/engine/Models.cpp

## Interfaces (frozen)
- `src/engine/Models.h`: everything declared there (signatures, data members, header comments = spec).
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/engine/tst_models.cpp`
- ctest name: `tst_models`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/E11 -G Ninja >/dev/null   # once
  cmake --build build-agents/E11
  ctest --test-dir build-agents/E11 --output-on-failure -R "^tst_models$"
  ```

## Spec notes
- Role names are part of the QML contract: `row col hitsLeft unbreakable alive tier`, `x y`, `type x y`, `kind x y`.
- Same count → `dataChanged` only (no reset/insert/remove) so QML delegates are not recreated every frame.
- Tests use `QAbstractItemModelTester`: begin/end calls must be correct.

- QML, other engine files, CMake, tests.
