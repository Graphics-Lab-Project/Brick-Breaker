## Goal
Paddle movement with speed settings 1–5, optional keyboard acceleration ramp, absolute pointer control and clamping.

## Allowed files (the ONLY files you may change)
- src/engine/PaddleLogic.cpp

## Interfaces (frozen)
- `src/engine/PaddleLogic.h`: everything declared there (signatures, data members, header comments = spec).
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)

- ctest name: `tst_paddle_logic`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/E2 -G Ninja >/dev/null   # once
  cmake --build build-agents/E2
  ctest --test-dir build-agents/E2 --output-on-failure -R "^tst_paddle_logic$"
  ```

## Spec notes
- Speeds 120/180/240/300/360 px/s (`K::PaddleSpeeds`). Clamp centre x to `[w/2, 336 − w/2]`.
- Acceleration: `heldTime += dt` first, then speed × `min(1, heldTime/0.15)`. A direction change restarts the ramp.
- `motionDir()` = inputDir if non-zero, else the pointer direction recorded since the last `step()` (cleared at the end of `step`).
- Edge cases tested: dt = 0, width change re-clamps, out-of-range speed setting.
