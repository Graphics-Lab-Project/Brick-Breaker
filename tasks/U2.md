| Model | Wave | Area | Depends on |

## Goal
Draw the paddle at `paddleX` with Long width tween, gun turret, laser nubs and the life-lost blink.

## Allowed files (the ONLY files you may change)
- qml/Paddle.qml

## Interfaces (frozen)
- `qml/Paddle.qml`: the Phase 0 stub's properties, signals, functions and the listed required `objectName`s.
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/qml/tst_paddle.qml`
- ctest name: `tst_paddle`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/U2 -G Ninja >/dev/null   # once
  cmake --build build-agents/U2
  ctest --test-dir build-agents/U2 --output-on-failure -R "^tst_paddle$"
  ```

## Spec notes
- `x = round(paddleX − width/2)`, `y = 322`, height 6. Width tweens 150 ms OutCubic only when polish is on.
- Gun shows `turret` (6×4, centred, y −4). Laser shows `nubLeft`/`nubRight` (4×4, y −4).
- `blink()`: opacity 0/1/0/1 in 75 ms steps. T1 effects run only when `polish` is true; with `polish: false` the component is static and fully correct.
