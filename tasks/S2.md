## Spec notes
- `runTimeMicros() = stepsToMicros(m_runPlaySteps)`, `levelTimeMicros() = stepsToMicros(m_levelPlaySteps)`.
- `startLevel` (new run): reset `m_runPlaySteps = 0` and `m_currentRunId = 0` (do this before `loadLevel`; `loadLevel` itself resets the level counters).
- Store creation: in `loadPersistentData()` (called by `setStoragePath`). Path rule: `native` -> `QStandardPaths::writableLocation(QStandardPaths::AppDataLocation) + "/scores.sqlite"`; INI path `X` -> `X + ".scores.sqlite"`; empty storage path -> `m_scoreStore.reset()`. Build a `SqliteScoreStore`; if `!isOpen()` keep it anyway (harmless). Then `refreshLevelBests()`. `setScoreStore(s)` replaces it, then `refreshLevelBests()`.
- `recordLevelClear()`: no store -> return. Else `LevelClearRecord{level = m_level, round = m_round, score = m_score - m_levelStartScore (>= 0), timeMicros = levelTimeMicros(), initials "", atUtc = QDateTime::currentDateTimeUtc()}`, `addLevelClear`, then `refreshLevelBests()`. (The timestamp is metadata, not game logic.)
- `recordRun()`: no store -> `m_currentRunId = 0`, return. Else `RunRecord{score = m_score, level = m_level, round = m_round, timeMicros = runTimeMicros(), initials "", atUtc = now}`, `m_currentRunId = addRun(...)`.
- `submitInitials` (existing): after the table accepted the initials, if `m_currentRunId > 0` call `m_scoreStore->setRunInitials(m_currentRunId, normalized initials)`. `m_currentRunId` must not be touched by a new run until `startLevel` resets it.
- `refreshLevelBests()`: rebuild `m_levelBests` with `K::LevelCount` maps `{bestScore, bestTimeMicros, clears}` (zeros without a store), emit `levelBestsChanged`. `levelBests()` returns the cache; before any refresh it must already return `K::LevelCount` zero entries (build it lazily or in the first call).
- `levelBest(n)`: map with the same three keys, zeros when n is out of 1..K::LevelCount or there is no store. `levelScores(n, limit)` = `topLevelScores`, `levelTimes(n, limit)` = `fastestLevelTimes`, `runScores(limit)` = `topRuns`: lists of maps with the keys in the header comments (`at` = `atUtc.toString(Qt::ISODateWithMs)`; ids are not exposed). Empty list for out-of-range level / no store.
