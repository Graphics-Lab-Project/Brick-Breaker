| Model | Wave | Area | Depends on |

## Goal
Grid/cell geometry and ball-vs-rect hit-axis rules used by every collision in the game.

## Allowed files (the ONLY files you may change)
- src/engine/Collision.cpp

## Interfaces (frozen)
- `src/engine/Collision.h`: everything declared there (signatures, data members, header comments = spec).
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/engine/tst_collision.cpp`
- ctest name: `tst_collision`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/E1 -G Ninja >/dev/null   # once
  cmake --build build-agents/E1
  ctest --test-dir build-agents/E1 --output-on-failure -R "^tst_collision$"
  ```

## Spec notes
- Implement every function declared in `Collision.h`; its comments are the spec.
- `cellsOverlapping` uses `Rect::intersects` (strict: touching edges do not count), clips to the 7×14 grid, returns `QPoint(col,row)` row-major.
- Edge cases tested: four-cell corner overlap, touching edge, board offset, rects outside the grid, zero velocity reflect.

- QML, other engine files, CMake, tests.
