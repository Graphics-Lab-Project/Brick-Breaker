## Spec notes
- 360 x 480, `Theme.bg` background, title "SELECT LEVEL" (Theme fonts/colours, same look as MenuScreen/OptionsScreen), BACK button
  (`objectName: "backButton"`, a small clickable Item with the text "BACK") and a hint "ESC BACK" is optional.
- `levelFlick`: a vertical `Flickable` (`interactive: true`) holding a Column of `levelCount` rows (`Repeater`), each ~36-44 px high with spacing so
  that the content is taller than the viewport (the viewport is roughly y 70..420). Mouse wheel and dragging scroll it for free.
- Row `objectName: "levelItem" + level`; properties `level` (1-based), `locked` (= level > unlockedLevel), `selected` (= index === currentIndex).
  Text "LEVEL 01".."LEVEL 10" via `Theme.pad(level, 2)`; locked rows are dimmed (`Theme.textDim`/`lineFaint`) and show a Text
  `objectName: "lockText"` "LOCKED" (visible only when locked); the selected row uses `Theme.accent`.
- Keys: Up/Down move `currentIndex` (clamped, no wrap) and call `ensureVisible()`; Return/Enter/Space -> `activate(currentIndex)`; Escape -> `back()`.
- `activate(i)`: emit `levelChosen(i + 1)` only when level i+1 <= unlockedLevel; otherwise do nothing. Click on a row: select it, then `activate`.
- `ensureVisible()`: set `levelFlick.contentY` directly (no animation) so the selected row is fully inside the viewport, clamped to
  `0 .. contentHeight - height`.
- Selection starts on the highest unlocked level: set `currentIndex = unlockedLevel - 1` in `Component.onCompleted` and whenever `visible` becomes true, then `ensureVisible()`.
- Declarative bindings; no images, no animations needed (T1 polish is out of scope).
