# [I2] Integration: AppRoot + Main window

| Model | Wave | Area | Depends on |
|---|---|---|---|
| sonnet | 4 | ui | G1, G2, G3, I1, U6, U7, U8 |

## Goal
Wire the real GameEngine into the screens, the 720×960 window and the frame driver.

## Allowed files (the ONLY files you may change)
- qml/AppRoot.qml
- qml/Main.qml

## Interfaces (frozen)
- `qml/AppRoot.qml`: the Phase 0 stub's properties, signals, functions and the listed required `objectName`s.
- `qml/Main.qml`: the Phase 0 stub's properties, signals, functions and the listed required `objectName`s.
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/qml/tst_app_root.qml`
- ctest name: `tst_app_root`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/I2 -G Ninja >/dev/null   # once
  cmake --build build-agents/I2
  ctest --test-dir build-agents/I2 --output-on-failure -R "^tst_app_root$"
  ```

## Spec notes
- AppRoot: menu/help/options/game switching (`screen` + `engine.gameState`); the visible screen holds focus; Options also opens from Pause and returns to the paused game; options requests → `engine.setPaddleSpeed/setAcceleration`; Quit → `Qt.quit()`.
- Main.qml: fixed 720×960 Window, black, root Item 360×480 with `scale: 2` (TopLeft), `GameEngine { storagePath: "native" }`, `FrameAnimation { running: true; onTriggered: engine.tick(frameTime) }`, FontLoaders for `qrc:/fonts/Silkscreen-Regular.ttf` and `-Bold.ttf`.
- Fonts are optional: if `fonts/*.ttf` is missing, the FontLoaders simply fail and Text falls back to the default font. Do not download anything.
- Smoke run (required): `QT_QPA_PLATFORM=offscreen timeout 3 ./build-agents/I2/brickbreaker` must end by the timeout (exit 124), not by a crash, and print no QML errors (a FontLoader warning about missing `fonts/*.ttf` is fine).
