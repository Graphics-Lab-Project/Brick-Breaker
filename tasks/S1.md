## Spec notes
- Connection: `QSqlDatabase::addDatabase("QSQLITE", name)` with a unique `name` per instance (e.g. `"bb_scores_" + QString::number(quintptr(this))` plus a counter); in the destructor close the db, drop all `QSqlQuery` objects first and then `QSqlDatabase::removeDatabase(name)`.
- File path: create the parent directory (`QDir().mkpath`) unless the path is `:memory:`. If the open fails or QSQLITE is missing: `m_open = false`, never crash, every method returns the "harmless" value documented in `ScoreStore.h`.
- Create the tables/indexes from the header comment with `CREATE TABLE IF NOT EXISTS`; set `PRAGMA user_version = 1` on a fresh database.
- Use prepared statements with bound values (no string-built SQL). `time_us` is bound as `qlonglong`. Timestamps are written/read as ISO-8601 UTC with milliseconds (`QDateTime::toString(Qt::ISODateWithMs)` / `fromString(..., Qt::ISODateWithMs)`, result in `Qt::UTC`). Invalid `atUtc` on add -> `QDateTime::currentDateTimeUtc()`.
- Orderings are in `ScoreStore.h` (`ORDER BY ... , id ASC` last). `limit <= 0` -> empty without querying. `levelBest`: MAX(score), MIN(time_us), COUNT(*) per level; 0/0/0 when no rows.
- `addLevelClear` / `addRun` return `lastInsertId` (> 0), `setRunInitials` returns true only if a row was updated. Store initials exactly as given (the engine normalizes them).
