## Goal
What each capsule does to the paddle mode, gun ammo and lives.

- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/E6 -G Ninja >/dev/null   # once
  cmake --build build-agents/E6
  ctest --test-dir build-agents/E6 --output-on-failure -R "^tst_powerups$"
  ```

## Spec notes
- Life: +1 life (max 9) and ends other powers. Multi: flag only. Long/Gun/Laser replace each other.
- Gun sets ammo 3 (refill if already Gun, which is not a mode change). Every non-Gun mode sets ammo 0.
- `resetForLifeLost`: back to Normal, ammo 0, lives untouched.
