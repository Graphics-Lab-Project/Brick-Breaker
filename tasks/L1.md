## Spec notes
- `unlockedLevel()` = `K::LevelCount` when `m_unlockAll`, else `m_unlockedLevel` (1..LevelCount).
- `startLevel(n)`: return if n < 1, n > `K::LevelCount` or n > `unlockedLevel()`. Then do exactly what `startGame()` does but with `n`
  (refactor `startGame()` to call `startLevel(1)`; keep the FSM guard `applyEvent(GameEvent::StartGame)` so Playing/Paused ignore it).
  Set `m_hasProgress = true` (emit `hasProgressChanged` only on change) and `savePersistentData()`.
- `unlockThrough(level)`: `level = min(level, K::LevelCount)`; if above `m_unlockedLevel` raise it; emit `unlockedLevelChanged` iff the
  *effective* `unlockedLevel()` changed; `savePersistentData()`. Never lowers. (`enterLevelCleared()` already calls it.)
- `setUnlockAll(on)`: emit `unlockAllChanged` on change, and `unlockedLevelChanged` iff the effective level changed. Never saved.
- Persistence keys `unlockedLevel` (int, default 1, clamp 1..LevelCount) and `hasProgress` (bool, default false) in
  `loadPersistentData()` / `savePersistentData()`; emit the changed signals when loading changes a value.
