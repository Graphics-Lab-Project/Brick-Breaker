## Spec notes
- Positions: HUD (8,8), pause button (328,74), hazard strip (8,98, 344×2), frame (8,100, 344×344), playfield (12,104), input hint y 448.
- Keys: Left/Right press/release → `moveLeft/moveRight(bool)` (ignore auto-repeat), Space → `launchOrFire()`, P/Escape → `togglePause()`.
- `pointerArea` MouseArea over the playfield (hoverEnabled): position → `setPointerX(x)` in field coords, click → `launchOrFire()`.
- Overlays visible by `gameState` (3/4/5). The visible overlay takes focus. Pause: resume → `togglePause`, options → `optionsRequested()`, quit → `quitToMenu`. Game over: initials → `submitInitials`, play again → `startGame`, menu → `quitToMenu`.
- Forward `lifeLost`/`lifeGained` to the HUD effects; call `levelBanner.play()` on `levelCleared`.
