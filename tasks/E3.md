## Spec notes
- Paddle: angle from vertical = clamp(offset/(w/2), −1, 1) × 60°, centre steep, edges shallow. Width ≤ 0 → straight up.
- Launch: 30° from vertical toward `dir` (dir 0 → right). Multi: −50/−20/20/50°, upward, in that order.
- Walls: push the centre back inside and make the velocity point away from the wall even if it already did. Bottom is open.
- `isLost`: top edge (`y − 3`) strictly below 336.
