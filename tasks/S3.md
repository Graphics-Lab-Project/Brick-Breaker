## Spec notes
- `formatTime(us)`: `M:SS.uuuuuu` from integer microseconds, minutes unbounded, seconds and microseconds zero-padded (use integer arithmetic: `Math.floor`, `%`; never floating point seconds). `formatTime(42318457) === "0:42.318457"`.
- Each row gets two Texts on the right (`fontS`, `Theme.text`/`Theme.textDim` colours, stacked inside the 40 px row): `objectName: "bestText"` -> `"BEST " + Theme.pad(bestScore, 5)` and `objectName: "timeText"` -> `formatTime(bestTimeMicros)`. Both are visible only when the row is NOT locked and `root.bests[index]` exists with `clears > 0`. Locked rows keep showing only `lockText`.
- Bindings must react to changes of `root.bests` (the engine replaces the whole list).
- `AppRoot`: `bests: root.engine ? root.engine.levelBests : []` on the `LevelSelectScreen`.
- Run the three tests of the regex above and keep them green.
