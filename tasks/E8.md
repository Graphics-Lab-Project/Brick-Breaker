# [E8] Engine: pace controller (speed + wall descent)

| Model | Wave | Area | Depends on |
|---|---|---|---|
| haiku | 1 | engine | none |

## Goal
Slow → Fast after 50 paddle hits in a life, then the wall descends one row per paddle hit (max 4).

## Allowed files (the ONLY files you may change)
- src/engine/PaceController.cpp

## Interfaces (frozen)
- `src/engine/PaceController.h`: everything declared there (signatures, data members, header comments = spec).
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/engine/tst_pace_controller.cpp`
- ctest name: `tst_pace_controller`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/E8 -G Ninja >/dev/null   # once
  cmake --build build-agents/E8
  ctest --test-dir build-agents/E8 --output-on-failure -R "^tst_pace_controller$"
  ```

## Spec notes
- The hit that switches to Fast does not descend; descent needs the state to already be Fast.
- `resetForLife` keeps the descent offset; `resetForLevel` clears it.

## Out of scope
- QML, other engine files, CMake, tests.
