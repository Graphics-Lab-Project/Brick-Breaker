## Goal
Top-5 table with 3-letter initials, persisted through QSettings.

## Allowed files (the ONLY files you may change)
- src/engine/HighScoreTable.cpp

## Interfaces (frozen)
- `src/engine/HighScoreTable.h`: everything declared there (signatures, data members, header comments = spec).
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/engine/tst_high_score_table.cpp`
- ctest name: `tst_high_score_table`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/E10 -G Ninja >/dev/null   # once
  cmake --build build-agents/E10
  ctest --test-dir build-agents/E10 --output-on-failure -R "^tst_high_score_table$"
  ```

## Spec notes
- Initials: trim + uppercase, must be exactly `[A-Z]{3}`. Ties: the new entry goes after existing equal scores.
- `qualifies`: score > 0 and (table not full or score > lowest).
- QSettings array `highscores` with keys `initials`/`score`/`level`; `load()` replaces contents.
