| Model | Wave | Area | Depends on |

## Goal
Bottom chevron row that lights while input is held, with a key hint between the chevrons.

## Allowed files (the ONLY files you may change)
- qml/InputHint.qml

## Interfaces (frozen)
- `qml/InputHint.qml`: the Phase 0 stub's properties, signals, functions and the listed required `objectName`s.
- Do not change any interface. If one looks wrong, report BLOCKED (AGENTS.md section 4).

## Acceptance test (read-only — never edit)
- File: `tests/qml/tst_input_hint.qml`
- ctest name: `tst_input_hint`
- Build + run (from the repo root):
  ```bash
  cmake -S . -B build-agents/U5 -G Ninja >/dev/null   # once
  cmake --build build-agents/U5
  ctest --test-dir build-agents/U5 --output-on-failure -R "^tst_input_hint$"
  ```

## Spec notes
- Chevron `lit` is `inputDir === ∓1`; colour accent when lit, else `chevronIdle`.
- Hint: Ready → `SPACE LAUNCH`; Playing with Gun/Laser → `SPACE FIRE`; otherwise empty.
